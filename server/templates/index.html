nodebench_ by InstantNode

Benchmark a server in one line.

CPU, disk and network, no root and nothing left behind. When it's done you get a link you can paste anywhere.

Run on any Linux box:

{{.OneLiner}}

Options pass them after bash -s --

  • -cskip the cpu test
  • -sskip the disk test
  • -nskip the network test
  • -4 / -6network tests over IPv4 or IPv6 only
  • -d DIRwhere to put the disk test file (default: current dir)
  • --no-sharedon't upload the result
  • --jsonprint the result as json
Results are public to anyone with the link. No IP addresses are stored. source on github
