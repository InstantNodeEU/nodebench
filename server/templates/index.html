What it measures

Numbers you can actually compare.

The same tools and parameters people already post on forums, so a result from your box lines up with everybody else's.

CPU

openssl speed

sha256 and aes-256-gcm on 16 KiB blocks, once on a single thread and once on all cores. openssl is on nearly every server and the run takes about 20 seconds.

  • sha256 1 + n threads
  • aes-256-gcm 1 + n threads
Disk

fio random read/write

A 50/50 mix with O_DIRECT, iodepth 64 and two jobs. Same settings as yabs. Falls back to a sequential dd test if fio can't run.

  • block sizes 4k / 64k / 512k / 1m
  • reported MB/s and IOPS
Network

iperf3, both directions

Send, receive and ping against public servers on four continents, over IPv4 and IPv6 when both work. Plain HTTP downloads if iperf3 is blocked.

  • Europe LON / AMS / FRA
  • Elsewhere NYC / LAX / SIN / GRU
Share it

Every run gets a link.

When the benchmark finishes it prints a short URL. The page shows the whole run, and the preview image means people see the headline numbers before they even click.

  • A result page with every table from the run
  • A 1200x630 preview card for Discord, Slack and X
  • Raw JSON at the same URL with .json
  • Or skip all of it with --no-share

How it works

Runs anywhere, leaves nothing.

Paste the line

Plain bash and curl, as a normal user. No package manager, no root, no agent.

Tools come and go

If fio or iperf3 are missing, static builds land in a temp directory, get checked against their sha256 sums and are deleted when the script exits.

Read it or share it

Results print as plain tables. The upload is exactly what --json shows, and you get the link back.

Options

Skip what you don't need.

-cskip the cpu test
-sskip the disk test
-nskip the network test
-4, -6network tests over IPv4 or IPv6 only
-d DIRdirectory for the disk test file (default: current dir)
-S SIZEsize of the disk test file, e.g. 512M (default: 2G)
-t Nthreads for the multi-core cpu test (default: all cores)
--no-sharedon't upload the result
--jsonprint the result as json, the share link goes to stderr

Pass them after bash -s --, for example {{.OneLiner}} -s -- -n --no-share

Privacy

Your IP stays with you.

The upload contains hardware, results and the provider name and country from the ASN lookup. No IP address is sent, and the server doesn't log one. Results are public to anyone who has the link, and --no-share keeps everything local.

Self-host

Run your own share server.

One Go binary, results stored as plain JSON files. Point the script at it with NODEBENCH_URL.

$ go build -o nodebench-server ./server
$ ./nodebench-server -base https://bench.example.com
