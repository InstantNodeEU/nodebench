Why Eygelshoven comes first

It's InstantNode's own network in the Netherlands, right next to Amsterdam and Frankfurt. We run nodebench, so we test against our own looking glass first. It's an ordinary location in the results and gets no special treatment.

When a server doesn't answer

Public iperf3 servers are shared and sometimes busy. nodebench tries up to three ports per server. If one direction still fails, the result shows it as failed instead of a misleading zero.
