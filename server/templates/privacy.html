Privacy

What a nodebench upload contains, what it doesn't, and how to get a result removed.

{{template "i-check"}}

What gets uploaded

  • Hardware: CPU model, cores, RAM, swap, disk size
  • OS, kernel, virtualization type, uptime
  • The benchmark numbers
  • Provider name, ASN and country of the server
  • A leaderboard name, only if you pass -L
{{template "i-x"}}

What doesn't

  • IP addresses. They're not part of the upload, and the server doesn't log them.
  • The city. Older versions of the script sent it, the server throws it away and never shows it.
  • Hostnames, user names, file paths
  • Cookies, trackers or analytics on this site

Exactly what you see

The upload is the same JSON that --json prints, so you can check it before sharing anything. With --no-share nothing leaves the server at all.

Who can see a result

Anyone who has the link. Result ids are random and not listed anywhere, unless you opt into the leaderboard with -L.

Rate limiting

To stop people filling the disk, the server counts uploads per IP address in memory for an hour. That counter is never written anywhere.

Removing a result

Send the result link to InstantNode through instantnode.eu/contact and it gets deleted. It helps if you can show the result is yours, for example by running the script again from the same server.
