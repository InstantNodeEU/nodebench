Privacy

What an upload contains, what it doesn't, and how to get a result removed.

What gets uploaded

  • Hardware: CPU model, cores, RAM, swap, disk size, disk type and filesystem
  • OS, kernel, virtualization type, uptime
  • The benchmark numbers and how long the run took
  • Provider name, ASN and country of the server
  • A leaderboard name, only if you pass -L

It's the same JSON that --json prints, so you can check it before sharing. With --no-share nothing is uploaded.

What doesn't

  • IP addresses. They're not in the upload, the nodebench server doesn't log them and the web server in front of it has its access log turned off.
  • The city. Older versions of the script sent it. The server drops it, also for results stored before that change.
  • Hostnames, user names, file paths.
  • There are no cookies, trackers or analytics on this site.

Who can see a result

Anyone who has the link. Result ids are random and results aren't listed anywhere unless you ran nodebench with -L. Then the result shows up on the leaderboard and under recent results on the home page.

Rate limiting

To stop people from filling the disk, the server counts uploads per IP address in memory for an hour. That counter is never written anywhere.

Removing a result

Send the link to InstantNode through instantnode.eu/contact and we delete it. It helps if you can show it's yours, for example by running the script again from the same server.
