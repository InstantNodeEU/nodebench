Run your own share server

The server is one Go binary. Results are stored as plain JSON files, there's no database to run next to it.

  1. Build it

    $ git clone https://github.com/instantnode/nodebench
$ cd nodebench/server
$ go build -o nodebench-server .

  2. Start it

    $ ./nodebench-server -base https://bench.example.com \
    -data /var/lib/nodebench -script ../nodebench.sh

    A systemd unit and an nginx config are in deploy/. Put it behind a reverse proxy for TLS and start it with -proxy so the upload limit sees real client addresses.

  3. Point the script at it

    $ curl -sL https://bench.example.com | NODEBENCH_URL=https://bench.example.com bash

    The server hands out the script itself when it's fetched with curl or wget, so the one-liner works against your host too.

Moderating the leaderboard

With an admin token set, this takes a result off the leaderboard. The result page itself stays online.

$ curl -X POST -H "Authorization: Bearer $TOKEN" \
    https://bench.example.com/api/results/<id>/hide

Storage

One small JSON file per result, sharded into folders by the first two characters of the id. Back up the data directory and you have everything, including the list of hidden results.
