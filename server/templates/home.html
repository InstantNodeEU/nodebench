We compare servers all day: ours, ones customers send us, ones we might buy. nodebench gives every run a link, so a benchmark can be shared like anything else.

What it measures

Three tests with tools that are already on most servers, set up so the numbers line up with what's posted on forums.

openssl speed

CPU

sha256 and aes-256-gcm on 16 KiB blocks, on one thread and on all cores. The steal time during the run shows how much CPU the host takes away.

fio

Disk

Random 50/50 read and write with 4k, 64k, 512k and 1m blocks, iodepth 64, O_DIRECT. The same parameters yabs uses.

iperf3

Network

Upload, download, ping and packet loss against {{$d.Sites}} public servers in Europe, the Americas, Asia and Australia, over IPv4 and IPv6 when the server has both.

Most of the work is done by other people's tools: fio, iperf3 and openssl speed. Static fio and iperf3 builds come from the yabs releases and are checked against their sha256 sums. nodebench runs as a normal user and removes everything it downloaded when it exits. How it works.

Options

Pass them after bash -s --. Combine as many as you like.

-c, -s, -n
skip the cpu, disk or network test
-4, -6
network tests over IPv4 or IPv6 only
-l REGIONS
only test these network regions: eu, na, sa, asia, oc
-x
all {{$d.Total}} test locations instead of the standard {{$d.Sites}}
-q
quick run with shorter tests and a 512M disk file
-d DIR
directory for the disk test file, default is the current one
-S SIZE
size of the disk test file, default 2G
-t N
threads for the multi-core cpu test, default is all cores
-L [NAME]
put the result on the leaderboard, optionally under a name
--no-share
don't upload anything
--json
print the result as json

{{.OneLiner}} -s -- -q -l eu

Frequently asked questions

The longer answers are in the docs.

Does it need root?
No. The disk test needs write access to the directory it runs in, -d picks another one.
What gets uploaded?
Hardware, results, provider and country, the same JSON --json prints. No IP address. Details on the privacy page.
How much traffic does it use?
Mostly the iperf3 tests, up to about 1.2 GB per location and direction on a gigabit port. Use -n, -l or -q on metered connections.
Can I run my own share server?
Yes, it's one Go binary that stores results as JSON files. See self-host.
