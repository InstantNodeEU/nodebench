nodebench

A benchmark script for Linux servers. It measures CPU, disk and network, prints plain tables and gives you a link to the result.

{{.OneLiner}}
{{$d.Terminal}}

A real run, copied from the terminal.

Why

We run servers in Eygelshoven, NL, and spend a fair amount of time comparing machines: ours, ones customers send us, ones we are thinking of buying. The usual benchmark scripts print good numbers, but you end up pasting screenshots of a terminal into tickets and chats. nodebench gives every run a link with the full result and a preview image, so a benchmark can be shared like anything else.

Most of the work is done by other people's tools. The disk test uses fio with the parameters from yabs, so the numbers line up with what's already posted on forums, and the static fio and iperf3 builds come from the yabs releases too. The network test is iperf3 against public servers, the CPU test is openssl speed. nodebench runs as a normal user and removes everything it downloaded when it exits.

Options

Pass them after bash -s --, for example {{.OneLiner}} -s -- -q -l eu.

-c, -s, -n
skip the cpu, disk or network test
-4, -6
network tests over IPv4 or IPv6 only
-l REGIONS
only test these network regions: eu, na, sa, asia, oc
-x
all {{$d.Total}} test locations instead of the standard {{$d.Sites}}
-q
quick run with shorter tests and a 512M disk file
-d DIR
directory for the disk test file, default is the current one
-S SIZE
size of the disk test file, default 2G
-t N
threads for the multi-core cpu test, default is all cores
-L [NAME]
put the result on the leaderboard, optionally under a name
--no-share
don't upload anything
--json
print the result as json

More on what each test does in the docs.

Questions

Does it need root?

No. The disk test needs write access to the directory it runs in, -d picks another one.

What gets uploaded?

Hardware, results, provider and country, the same JSON --json prints. No IP address. Details on the privacy page.

How much traffic does it use?

Mostly the iperf3 tests, up to about 1.2 GB per location and direction on a gigabit port. Use -n, -l or -q on metered connections.
